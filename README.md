# USSH

A simple shell wrtten in C.

## BUILD

clone directory
```bash
    git clone https://github.com/Penrose480/ussh.git
    cd ussh
```

make
```bash
    sudo make clean install
```

run
```bash
    ussh
```

## ABOUT

Supports basic builtins, such as cd and exit, command line arguments, and signal handling.
